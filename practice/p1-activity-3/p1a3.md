# Robocop


We had a problem which was that as a small studio with multiple active git repositories, managing agent development workflow across the projects was cumbersome but also difficult to standardize without something to help coordinate it.

We have used spec-driven development, with product requirements directly in the git repository, all of this year. Our approach to spec-driven development along with the standard agent harness configurations and utilities like skills, rules, hooks etc were also constantly being updated, and the great majority of all changes apply equally to any project we work on.

RepoCop is designed to be a lightweight, adaptable solution to this problem to meet our particular needs. It is *not* meant to be a robust, production-ready solution for medium-to-large enterprises.

It provides a web app dashaboard to synchronize all the afoementioned agent development utilities to git repositories, and also display the progress of specs work so that the status of specifications is clear.
